## Contexto

A sessão 26 (28/03/2026) definiu a ISA-95 / IEC 62264 como linguagem organizacional da CSN. Toda a arquitectura foi reestruturada segundo as 4 partes da norma (IEC 62264-1 a 62264-5), com 5 níveis funcionais (L0-PHY a L4-BPL), tipos de sistema standard (Máquinas/PLC/SCADA/MES/ERP), MESA-11 como checklist L3, e codificação interna de documentos (CSN-L[nível]-[secção]-[seq]-[ano]).

Os 25 ADRs existentes foram escritos antes desta reestruturação. Nenhum referencia níveis ISA-95, códigos internos, tipos de sistema, ou o princípio P8 (personas abaixo do núcleo). Este ADR audita todos os ADRs anteriores e classifica-os face à nova estrutura.

## Princípios estabelecidos na sessão 26

- **P7:** ISA-95 como espinha dorsal — toda a arquitectura organizada pelos 5 níveis
- **P8:** Personas abaixo do núcleo — interlocutoras, não produzem, agentes núcleo fazem todo o trabalho
- **MESA-11:** Checklist obrigatório para L3-MOM (11 funções MES)
- **Codificação:** CSN-L[nível]-[secção]-[seq]-[ano] em todos os documentos
- **Quadro central:** L4-BPL(ERP) / L3-MOM(MES) / L2-SUP(SCADA) / L1-SEN(PLC) / L0-PHY(Máquinas)

## Decisão

### Regra de imutabilidade

ADRs aceites não são alterados. Se o conteúdo de um ADR entra em conflito com a reestruturação ISA-95, o ADR mantém-se como registo histórico e este ADR-026 documenta a divergência. Novos ADRs substituem quando necessário.

## Consequências

**Positivas:**
- Todos os 25 ADRs estão agora mapeados contra a estrutura ISA-95
- 4 ADRs supersedidos ficam documentados como histórico — não apagados
- Fica claro que ADRs futuros devem obrigatoriamente incluir nível ISA-95 e código interno
- A regra P8 (personas abaixo do núcleo) fica formalizada como decisão arquitectural

**Regras para ADRs futuros (obrigatório a partir deste ADR):**
1. Código interno: CSN-L[nível]-[secção]-ADR-[seq]-[ano]
2. Nível ISA-95 explícito
3. Referência ao módulo afectado (BPL/MOM/SUP/SEN/PHY)
4. Se envolve persona: declarar que é Camada 2 (interlocutora, não produz)
5. Se envolve agente núcleo: declarar que é Camada 3 (produz, invisível)
