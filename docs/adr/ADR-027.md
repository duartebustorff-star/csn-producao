## Contexto

O sistema tem 10 agentes núcleo (Camada 3) definidos na arquitectura v27. O Agente RH (CSN-L3-RH-AGT) está listado como "Em definição" mas já tem:
- Migration 021 executada
- Tabelas: colaboradores_rh (22 colunas), recibos_vencimento (23 colunas), processamentos_mensais, ausencias, documentos_rh
- Routes: /api/rh/recibo, /api/rh/declaracao-anual, /api/rh/colaboradores
- 5 tools Carolina no chat-tools.ts (recibos, ferias, saldo, dados, resumo_rh)
- 45 recibos processados (Jan 2025 → Mar 2026, 3 colaboradores, 0 lacunas)

## Decisão

O Agente RH é formalmente o 11º agente autónomo da Camada 3 (núcleo).

## Arquitectura

### Separação de responsabilidades

| Componente | Camada | Função | Produz documentos? |
|-----------|--------|--------|-------------------|
| Carolina | 2 (Persona) | Fala com workers sobre RH. Mostra recibos, saldos, férias. | NÃO |
| Agente RH | 3 (Núcleo) | Calcula salários, gera recibos PDF, processa declarações anuais. | SIM |

### O que o Agente RH faz (Camada 3)

1. **Processamento mensal** — calcula vencimento base, sub. alimentação, duodécimos, descontos SS/IRS, líquido
2. **Geração de recibos** — produz PDF por colaborador/mês
3. **Declaração anual** — gera documento anual por colaborador
4. **Gestão de ausências** — regista férias, baixas, faltas
5. **Manutenção cadastral** — actualiza dados fiscais (NIF, NISS, taxas, IBAN)

### O que o Agente RH NÃO faz

- Não fala com workers → isso é a Carolina
- Não gere qualificações de produção (EN 9606) → isso é L0-PER (Personnel Model)
- Não gere alocação a fases/obras → isso é PRD (Production Operations)
