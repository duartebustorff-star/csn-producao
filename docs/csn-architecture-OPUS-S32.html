ISO 22400 - KPIs para Manufacturing Operations Management

Norma adoptada: ISO 22400-1:2014 + ISO 22400-2:2014

Define 34 KPIs padronizados para o nivel L3-MOM, organizados em 3 niveis hierarquicos: elementos de medicao, KPIs basicos, e KPIs abrangentes. Alinhada com IEC 62264 (ISA-95).
