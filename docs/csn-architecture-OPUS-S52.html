Novidade em L3-DOC: catálogo de fornecedor como entidade de primeira classe

O catálogo FUSO é o segundo fornecedor integrado (após Renault Master XDD, 20 configs em catalogo_chassis). A sessão S52 estabeleceu o padrão arquitectural para fornecedores de chassis:

Tabelas Supabase por fornecedor

2 tabelas dedicadas: fichas_tecnicas_fuso (diesel, ~62 cols) + fichas_tecnicas_fuso_ecanter (eléctrico, ~61 cols). Schemas diferentes porque eCanter não tem motor combustão — tem e-axle, battery, charging. Unificação via VIEW v_catalogo_fuso UNION ALL.

Decoder por fornecedor

fuso_decoder_codigo decodifica o fuso_model_code 12-13 chars. Permite à Marta responder "cliente tem um FECX1GL3SEUY" = 9C18 DUONIC WB 3850. Dados de referência estáveis.

Fichas legacy suportadas

Campo ficha_valida_em + extraido_de permitem coexistir fichas de 2018, 2021, 2024 para o mesmo fuso_model_code. Clientes com veículos antigos (não disponíveis no site FUSO) entram pelo Agente Documental.

Agente Documental integrado

Skill analise-ficha-fuso (a criar em S53) vai extrair automaticamente novas fichas que cheguem por email. Verificação de duplicados por fuso_model_code. Resposta à Marta sobre variantes existentes.
