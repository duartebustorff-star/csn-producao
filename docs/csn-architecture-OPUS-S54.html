L4-ENG — Convenção Inventor CSN NOVO S54

Nomenclatura, sistema de coordenadas e convenções de parâmetros para todas as peças e assemblies Inventor da CSN. Aplicável a novas modelações e remodelações (longarinas Fiat, bases universais, travessas, caixa aberta).

Sistema de coordenadas

  • X = 0 no eixo traseiro do chassis
  • +X direcção cabine · −X direcção traseira
  • +Y esquerda (ISO 8855) · −Y direita
  • Z = 0 plano XY = face inferior das peças da carroçaria
  • Convenção abreviada: Px, Nx, Py, Ny

L3-MOM — CSN NestHub NOVO S54

Módulo integrador entre modelação (Inventor) e máquina de corte (Bodor A3T6). Não substitui motor de nesting especializado — gere ciclo de obra, agregação de peças, rastreabilidade EN 1090 e interface com operador.

Arquitectura em 4 etapas

ETAPA 1 — EXPORT (contínuo, dia da modelação)
  Inventor + rule CSN_Export_Nesting_v2
    → C:\CSN\Obras\{obra_id}\Chapas\ (DXF flat patterns)
    → C:\CSN\Obras\{obra_id}\Tubos\  (STEP AP214)
  Registo em Supabase: nesting_queue (status="exported")

ETAPA 2 — AGREGAÇÃO (domingo 20h00, automático)
  Agente CSN lê nesting_queue (obras activas)
  Copia ficheiros agrupados por perfil/espessura/material:
    C:\CSN\NestingPool\Tubos\80x40x3_S235\
    C:\CSN\NestingPool\Chapas\t=3mm_S235\
  Nome ficheiro: {obra_id}_{peça}_{perfil}_{material}_{NNN}.{dxf|step}
  Status="ready_to_cut"

ETAPA 3 — CORTE (segunda ou terça, manual)
  Operador Bodor A3T6:
    - Portal mostra "Próximo corte: {data} tipo={chapa|tubo}"
    - Operador escolhe tipo da sessão
    - Software de nesting (Almacam Tube para tubo / gratuito para chapa)
      lê o pool e gera programa óptimo
    - Ao importar: ficheiros movem-se para NestingPool\_processed\{data}\
    - Corte em série (várias obras agregadas na mesma barra/chapa)
  Status="cut"

ETAPA 4 — RASTREABILIDADE (pós-corte)
  Cada peça cortada volta à pasta da obra:
    C:\CSN\Obras\{obra_id}\Corte_Realizado\
  Registo Supabase: status="in_production", data_corte, operador, programa
  Palete por obra com etiqueta QR → portal operário lê QR
  Dossier EN 1090 recebe automaticamente: certificado 3.1 do lote +
    programa de corte + data + operador

Tabela nesting_queue (schema planeado S55)

CREATE TABLE nesting_queue (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  obra_id text REFERENCES obras(id),
  ficheiro_path text NOT NULL,
  ficheiro_nome text NOT NULL,
  tipo text CHECK (tipo IN ('CHAPA', 'TUBO')),
  perfil_ou_espessura text,
  material text,
  peca_origem text,
  quantidade integer DEFAULT 1,
  status text CHECK (status IN (
    'exported','ready_to_cut','in_nesting','cut','in_production','consumed'
  )),
  data_export timestamptz DEFAULT now(),
  data_agregacao timestamptz,
  data_corte timestamptz,
  data_consumo timestamptz,
  programa_corte text,
  nesting_batch text
);
