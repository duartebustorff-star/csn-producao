PRINCÍPIO CENTRAL — NÃO NEGOCIÁVEL
O CSN Opus é a implementação digital das normas que regulam o fabrico de carroçarias na UE. O CSN Brain é o produto comercial que vende este conhecimento ao mercado.
Cada módulo existe porque uma norma obriga. Cada tabela guarda uma evidência. Cada documento gerado é uma prova de conformidade. A secção Prontidão para Auditoria é NUNCA removida de nenhuma versão deste documento.
