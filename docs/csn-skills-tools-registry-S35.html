Como Criar um Skill

Processo — Claude Code lê o SKILL-GUIDE.md e sabe o que fazer

  1. Identificar o domínio: qual dept. ISA-95? fornecedor ou departamento?
  2. Criar a pasta: mkdir -p skills/[dept]/ ou skills/fornecedores/[nome]/
  3. Criar SKILL.md com campos obrigatórios: name, version, date, isa95_level, department, norm, status
  4. Escrever: Contexto + Instruções + Tools disponíveis (read-only) + Exemplos + Escalação
  5. Adicionar linha ao skills/REGISTRY.md com data/hora, tipo, caminho, nível, estado
  6. git add skills/ && git commit -m "skill: [nome] — [dept] ISA-95 [nivel]" && git push

Como Criar uma Tool

Processo — endpoint API + documentação

  1. Identificar necessidade: que dados? leitura ou escrita? que tabela Supabase?
  2. Criar endpoint: src/app/api/[dept]/[nome]/route.ts
  3. Criar doc: tools/[dept]/[nome].md com: route, method, isa95_level, access (read/write), input, output, tabelas
  4. Adicionar linha ao skills/REGISTRY.md com data/hora, tipo tool, rota, acesso, estado
  5. git add src/app/api/ tools/ && git commit -m "tool: /api/[dept]/[nome]" && git push
  6. Deploy: npx vercel --prod
