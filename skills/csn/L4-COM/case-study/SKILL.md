# Case Study / Portfolio — CSN Technic

## Estrutura de case study (1 página)

### 1. Título
`[Tipo carroçaria] para [Sector] — [Empresa/zona]`
Ex: "Tribasculante Hardox para terraplanagens — Grande Lisboa"

### 2. O desafio (2-3 frases)
O que o cliente precisava, que problema tinha, que restrições existiam.

### 3. A solução (3-4 frases)
O que a CSN fez — tipo de carroçaria, materiais, soluções técnicas específicas.

### 4. Especificações (tabela)
| Parâmetro | Valor |
|-----------|-------|
| Veículo | [Marca Modelo PBT] |
| Carroçaria | [Tipo CxLxA] |
| Material | [fundo/laterais] |
| Acessórios | [lista] |
| Prazo | [semanas] |

### 5. Resultado (1-2 frases)
Impacto para o cliente — operacional desde [data], sem problemas, repetiu encomenda.

### 6. Foto
Sugestão de foto necessária (3/4 do veículo, limpo, ao ar livre).

## Regras

- Nunca publicar nome do cliente sem autorização
- Se não tiver autorização, usar "[Empresa de terraplanagens na zona de Lisboa]"
- Incluir sempre pelo menos 1 dado técnico concreto
- Tom factual — sem exageros, sem "o melhor", sem superlativos
- Incluir certificações como diferenciador

## Output

Gerar em markdown ou docx. Se for para website, gerar HTML. Se for colecção de vários, gerar portfolio com índice.
