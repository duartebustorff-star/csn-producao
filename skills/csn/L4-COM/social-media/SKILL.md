# Social Media — CSN Technic

## Contexto

CSN Technic usa redes sociais para mostrar trabalho, gerar leads, e construir autoridade no sector de carroçarias para comerciais. O conteúdo é criado internamente pelo Duarte.

## Tom por plataforma

### LinkedIn — Profissional + técnico
- Tom: autoridade técnica, dados concretos, certificações
- Formato: texto com foto ou carrossel
- Público: decisores, gestores de frota, transportadores
- Frequência ideal: 2-3x/semana

### Instagram — Visual + bastidores
- Tom: orgulho no trabalho, processo de fabrico, antes/depois
- Formato: foto carrossel, reels curtos, stories
- Público: sector construção, transportes, curiosos
- Frequência ideal: 3-5x/semana (incluindo stories)

### Facebook — Comunitário + local
- Tom: proximidade, empresa local, equipa
- Formato: foto com texto, partilha de marcos
- Público: empresários locais, clientes existentes
- Frequência ideal: 2-3x/semana

## Tipos de conteúdo (rodar entre estes)

### 1. Obra concluída (40% dos posts)
```
[FOTO da carroçaria montada no veículo]

✅ Mais um [basculante tribasculante / caixa aberta / estrado] 
montado num [Marca Modelo] para a [Empresa/sector].

Especificações:
→ [CxLxA]mm em aço [material]
→ [Detalhe técnico relevante]
→ Certificação EN 1090

#carroçarias #basculante #CSNTechnic #fabricado_em_portugal 
#veiculos_comerciais #metalomecanica #mafra
```

### 2. Processo de fabrico (25%)
```
[FOTO/VÍDEO do processo — corte laser, soldadura robot, montagem]

O que parece simples tem muita engenharia por trás.
[Descrever o que se vê na foto — ex: "Corte laser a 6kW 
num fundo Hardox 450 de 4mm. Precisão ao décimo."]

Cada peça é cortada, soldada e montada aqui em Mafra.

#fabricação #laser #soldadura #Bodor #KUKA #made_in_mafra
```

### 3. Técnico / educativo (15%)
```
Sabia que um basculante tribasculante pode descarregar 
para 3 lados? Ideal para obras com espaço limitado.

[Explicar conceito técnico de forma simples — 
payload, tipos de basculamento, materiais, etc.]

Na CSN projectamos cada carroçaria ao milímetro 
para o chassis do cliente.

#dica_tecnica #basculante #engenharia
```

### 4. Equipa / bastidores (10%)
```
[FOTO da equipa, da fábrica, do café da manhã, da máquina nova]

[Texto humano sobre a equipa, a fábrica, um marco, 
uma melhoria, uma aquisição]

#equipa #CSNTechnic #bastidores #mafra
```

### 5. Marco / certificação (10%)
```
[FOTO do certificado, da auditoria, do marco]

[Anunciar certificação, número de obras, anos de actividade, etc.]

#certificação #EN1090 #ISO9001 #qualidade
```

## Regras

- Nunca usar linguagem corporativa vazia ("soluções integradas", "comprometidos com a excelência")
- Mostrar trabalho real, não stock photos
- Incluir sempre pelo menos 1 dado concreto (medida, material, certificação)
- Hashtags: máximo 10 no Instagram, 3-5 no LinkedIn, 3-5 no Facebook
- Emojis: moderados no Instagram, mínimos no LinkedIn, moderados no Facebook
- Legendas curtas: máximo 150 palavras no Instagram, 200 no LinkedIn
- Nunca revelar preços nas redes sociais
- Não publicar fotos de clientes sem autorização

## Output

Gerar post pronto a copiar com: texto + hashtags + sugestão de foto. Se o utilizador fornecer foto, adaptar o texto à foto. Se pedir calendário, gerar plano semanal/mensal.
