# relatorio-gestao-mensal — CSN Technic

## Contexto
CSN Technic fabrica carroçarias para veículos comerciais 3.5T–12T em Mafra, Portugal.
Tipos: basculantes, caixas abertas, estrados, plataformas. Certificações: EN 1090, EN ISO 3834, ISO 9001.

## Quando usar
- Fim de cada mês
- Preparação para reunião gestão
- Acompanhamento investidor

## Estrutura
1. Resumo executivo (3 frases)
2. Produção: obras concluídas, em curso, pipeline
3. Financeiro: facturação, custos, margem, cash flow
4. Comercial: leads, propostas, conversão
5. Qualidade: NCs, inspecções, certificações
6. Recursos: horas trabalhadas, ausências
7. Próximo mês: previsão, riscos, oportunidades
